# 시각 명세

시각 명세는 구현자가 간격을 짐작하지 않게 하는 문서다. 내용을 함께 고치면 페이지 설계와 서로 다른 문구가 생긴다.

## 기준

- 페이지 설계의 화면 목록과 문구를 그대로 둔다.
- 관련 정보 마크다운의 단 구성, 이미지 위치, 전체 캡처 설명을 배치의 근거로 쓴다.
- 요구 파일에 확정된 시각 변경만 원본과 다르게 적는다.

## 출력

`_workspace/02_web-designer_visual.md`

```markdown
# 시각 명세
## [화면 이름]
- 영역과 정렬:
- 반복되는 요소:
- 텍스트 위계:
- 색과 구분:
- 누르기 전, 이후, 오류처럼 문서에 있는 상태:
- 좁은 화면에서 유지할 관계:
- 근거: 문서 위치 또는 요구 번호
- 확인 불가:
```

수치를 문서에서 읽을 수 없으면 값을 만들지 않고 `확인 불가`에 적는다. 페이지 설계에 없는 화면을 추가하지 않는다.
