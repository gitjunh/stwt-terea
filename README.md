# Homepage Creator

웹사이트 URL과 관련 정보 마크다운을 입력으로 받아, 원본 웹사이트를 그대로 복제합니다.

화면 구성, 문구, 이미지, 링크, 사용자 흐름은 원본을 기준으로 맞춥니다. 새 디자인이나 기능 추가는 이 프로젝트의 범위가 아닙니다.

## 입력

복제 한 건은 아래 두 가지로 구성합니다.

| 입력 | 역할 |
| --- | --- |
| 웹사이트 URL | 복제 대상. 화면과 동선을 맞출 기준 주소 |
| 관련 정보 `.md` | URL만으로 드러나지 않는 화면 설명, 절차, 문구, 이미지, 레이아웃 |

마크다운은 페이지 단위로 작성합니다. 각 페이지에는 레이아웃, 이미지 위치, 화면 문구, 원본 URL을 남깁니다. 샘플의 `document.md`가 이 형식입니다.

## 출력

입력한 URL의 화면을 재현한 웹사이트입니다. 방문자가 보는 페이지와, 문서에 적힌 관리·신청 흐름이 원본과 같아야 합니다.

## 디렉터리

```text
samples/
  <사이트>/
    <화면>/
      document.md    # 해당 화면의 관련 정보
```

## 샘플

켐코 방문 시스템을 두 화면으로 나눠 두었습니다.

| 경로 | 대상 URL | 내용 |
| --- | --- | --- |
| `samples/kemco/kemco_visitor/` | https://visitor.koreaenergymaterials.com/Visitor | 외부 방문객 방문신청 |
| `samples/kemco/kemco_admin/` | https://visitor.koreaenergymaterials.com/Manager | 임직원 방문예약·승인 |

각 폴더의 `document.md`는 원본 안내 자료를 페이지별로 옮긴 파일입니다. 레이아웃, 캡처, OCR 문구, 출처 URL이 들어 있습니다.

## 복제 원칙

- 기준은 제공된 URL과 마크다운입니다.
- 문구, 순서, 버튼, 링크는 문서에 적힌 내용을 유지합니다.
- 문서와 URL이 다르면 URL의 실제 화면을 우선하고, 차이는 문서에 남깁니다.
