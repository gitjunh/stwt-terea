# terea 방문·관리 로컬 복제

Vite + React + TypeScript. 원본 운영 사이트 계정은 사용하지 않습니다.

## 실행

```bash
npm install
npm run dev
npm test
```

## 로컬 관리 테스트 계정

시드: `src/auth/adminAccounts.ts` (`LOCAL_ADMIN_SEED`)

| 항목 | 값 |
| --- | --- |
| ID | `terea-admin` |
| PW | `terea-admin-local-01` |

관리 로그인: `/manager/login`
